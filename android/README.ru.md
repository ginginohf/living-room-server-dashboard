# Android TV: заставка и ручной просмотр

Исходный готовый экран: графики, часы, температура, диски, сеть, курсы при включении на сервере. Личные endpoint/token, скриншоты реального сервера, APK, логи и настройки телевизора не включены.

## Сборка

Нужны JDK17 и Android SDK34. Задайте JAVA_HOME и ANDROID_HOME для своего устройства; Gradle wrapper8.9 скачает нужный дистрибутив с проверкой SHA256.

```sh
./gradlew --no-daemon assembleDebug lintDebug
```

APK: app/build/outputs/apk/debug/app-debug.apk. Установить на собственный телевизор: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Запустить приложение «Домашний сервер», ввести URL сервера с `/metrics` и созданный на сервере DASHBOARD_TOKEN. Для изменения настроек — кнопка MENU на пульте в режиме ручного просмотра. Если пульт не имеет MENU, очистите данные приложения и настройте заново.

Выберите заставку в системных настройках Android TV. Конкретный пункт зависит от прошивки; приложение не заменяет домашний лаунчер автоматически. `ServerDream` завершает заставку по действиям пульта. Чтобы отказаться, выберите прежнюю заставку в настройках, затем удалите приложение.

## Секреты и транспорт

Токен вводится пользователем после установки и сохраняется в приватных SharedPreferences приложения, не в исходниках и не в APK. Это не защищает от администратора/root самого телевизора. allowBackup=false. HTTP включён для доверенной локальной сети; для защиты токена в пути используйте HTTPS. Собственные ключи подписи release не входят в репозиторий. `assembleRelease` создаёт неподписанный release; для распространения настройте собственную подпись вне Git.

Application ID подготовленной версии: `local.homelab.dashboard`; она не заменяет прежнюю частную установку автоматически. Сборку на физическом телевизоре после изменения конфигурации ещё не проверяли.
